# Bundled font licence

ORBIT Planner bundles **Plus Jakarta Sans** (variable weight, `app/src/main/res/font/plus_jakarta_sans.ttf`).

- Source: https://github.com/google/fonts/tree/main/ofl/plusjakartasans (also https://github.com/tokotype/PlusJakartaSans)
- Copyright 2020 The Plus Jakarta Sans Project Authors (https://github.com/tokotype/PlusJakartaSans)
- Licence: SIL Open Font License, Version 1.1 - https://openfontlicense.org (full text: https://scripts.sil.org/OFL)

The OFL permits using, embedding and redistributing the font in applications, including commercial ones, provided the
font is not sold on its own and this copyright and licence notice is kept with it. The font is not modified.
Scripts it does not cover (Urdu, Arabic, Hindi, Bangla ...) fall back to the system font.
