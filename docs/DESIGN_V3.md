# ORBIT design v3 — refinement brief (supersedes colour/shape details of DESIGN_BRIEF.md where they conflict)

User feedback on v2 (on a real phone): colours are good but "do not attract the eye" and feel a bit harsh; white cards look flat/plain; spacing between Home cards too small and every card looks the same; font family should be nicer; the language rows should be taller and the list must scroll smoothly (no half-faded rows); the top-bar icon tile should have a very light gradient; the bottom bar should put ONE important feature in the centre (PrankHub's notched bar with a raised centre button); Rate-us sheet design is poor; premium needs a "black" variant and a "zippo-style" comparison variant; nothing may ever overlap; contents of cards must auto-adjust (wrap, ellipsize, min heights, flow layouts) with no overlapping at any font scale; app icon should match modern trending planner apps.

## 1. Palette (calmer, more reliable, still attractive)
Keep violet as the brand accent but make surfaces calmer and add warm sparkle:
- Light: background `#EEF0F9` (cool lavender-grey, easy on the eyes), card base `#FBFBFF` with a faint top-to-bottom tint to `#F4F4FD` (cards are NOT flat white), well `#E7E9F6`, hairline `#6C47FF @ 12%`, text `#171538`, muted `#5E5C80`.
- Primary `#6A4DF4` (gradient to `#9B5CF6`), secondary cyan `#0EA5C6`, tertiary coral `#F0617D`, warm highlight amber `#FFB23F` used for badges, stars, streak flames, the centre button's ring and premium accents.
- Dark: background `#0C0B1E`, card `#16142F` → `#1B1838` tint, well `#201D45`, text `#F0EFFF`.
- Hero gradients stay vivid but are used only for hero areas; ordinary cards get an accent-tinted variant (accent @ 8–10% over the card colour) instead of a plain white one, e.g. `OrbitCard(tint = accent)`.
- Contrast must stay ≥ 4.5:1 for text.

## 2. Typography
Bundle a professional font family (OFL licensed) — use **Plus Jakarta Sans** (variable font) downloaded from the Google Fonts GitHub repository (`https://github.com/google/fonts/raw/main/ofl/plusjakartasans/PlusJakartaSans%5Bwght%5D.ttf`, plus the italic if needed is not required), save as `res/font/plus_jakarta_sans.ttf`, and create a `FontFamily` using `Font(R.font.plus_jakarta_sans, weight = FontWeight.X, variationSettings = FontVariation.Settings(FontVariation.weight(X)))` for Normal/Medium/SemiBold/Bold/ExtraBold (API 26+ supports variable fonts; minSdk is 26). Scripts it does not cover (Arabic, Urdu, Hindi, Bangla, Cyrillic is covered, Latin Extended covered) fall back to the system font automatically — verify the typography still looks consistent. Slightly adjust the scale: titleLarge 20/28 ExtraBold-ish, body 15/22, labels 12–13, letter-spacing small negative on large titles. Reduce excess size/weight in places where text looked too large (premium titles, section headers).

## 3. Cards and surfaces
`OrbitCard` gains a subtle vertical gradient fill, optional `tint: Color?` (accent-tinted variant), optional `elevation` style (flat / soft / lifted) with the same hairline stroke width (0.8dp) and a softer, lower-contrast glow. Provide 3 card styles used for variety: **Soft** (default), **Tinted** (accent @ 8–10%), **Glass** (for use on hero gradients: white @ 14% with hairline white @ 24%). Content inside cards must never overlap: use `Modifier.heightIn(min=…)` instead of fixed heights, `FlowRow`/`weight` with `maxLines` + ellipsis, `Modifier.wrapContentHeight`, and wide-font-scale fallbacks (stack vertically when width is tight; e.g. use `BoxWithConstraints`/`FlowRow`).
Top bar: the leading `IconTile` in `OrbitTopBar` gets a *very light* gradient (accent @ ~16–22% to transparent-ish with the glyph in the accent colour on tinted background — a soft tinted tile rather than a saturated one) for sub-screens like Language/Settings; tab screens keep a slightly stronger version. Keep a gentle wash behind the status bar.
Empty states get nicer artwork: layered soft circles + the accent glyph + a small decorative orbit ring (Canvas) + title/message/CTA; `EmptyState` is used everywhere, so improve it centrally.

## 4. Bottom navigation with a centre feature (PrankHub-style notched bar, own design)
Floating pill bar (inset 16dp sides, 12dp bottom) with a circular concave notch at the top centre and a raised 56dp **gradient "+" (Quick add)** button sitting in the notch with a warm amber ring and glow. Tabs: Home, Tasks | (+) | Calendar, More — 2 tabs on each side of the centre. **Projects moves into More** (as the first tile) and stays reachable from the Home projects card and the Quick-add sheet; keep `AppDestination.Projects` working as a normal pushed destination (it must show a back button when not reached through a tab — check `ProjectsScreen` handles `onBack`; if it is a tab-only screen, the shell must also render it as a sub-screen; coordinate by making `ProjectsScreen` accept being opened from More without bottom bar: the shell's `BOTTOM_TABS` becomes [Home, Tasks, Calendar, More]; Projects then is shown without the bar and with a back arrow — add an `onBack` parameter default null OR read a `showBack` flag; implement what is least invasive and keep the existing signature `ProjectsScreen(nav)` by deriving back-button presence from `nav` (e.g. `nav.canGoBack`)).
Tab items: icon in a soft tinted pill when selected (gradient indicator), label shrinks in 0.5sp steps down to 9sp until it fits on one line (like PrankHub), resets on language/width change. Tapping the centre button opens a floating `OrbitSheet` "Quick add" with 5 big colourful tiles (New task, New note, New habit, New project, New goal) + Search; it must also close on selection and navigate. First-run hint tooltip above the centre button ("Add anything in one tap") shown until dismissed once (persist with a new SettingsStore boolean — add it yourself in `core/datastore/SettingsStore.kt`, key `quick_add_hint_dismissed`).
The bar's total height budget: keep ~96dp content bottom padding contract for tab screens (the raised button needs 8–12dp more: use 112dp as the new bottom contract and export `const val BOTTOM_BAR_CONTENT_PADDING = 112.dp` in `core/designsystem`; update the places that hard-code 96dp/104dp in tab screens: Home, Tasks, Calendar, More, Projects, Notes/others if tab-hosted).

## 5. Language screen
Selected and unselected language cards are taller (≥ 64dp, 16dp radius, generous padding); the list is a single `LazyColumn` (no entrance animation that leaves rows half-faded — rows must be fully visible immediately; allow only a quick one-time fade of the whole list), scrolls smoothly with a proper bottom content padding so the last row clears the system bar and (later) a native-ad slot (leave a stable `item` slot position at the end: `AdSlotPlaceholder` area will be filled by the ads work — keep a clearly named `@Composable private fun NativeAdSlot()` hook that currently renders nothing; the ads agent will wire it).

## 6. Home
More vertical space between cards (24dp between sections, 16dp inside), each section a clearly different composition: hero (gradient) → quick-add chips row → today (accent-edge card) → upcoming (horizontal date chips) → habits (circular check row) → projects (horizontal gradient cards) → overview (2×2 tinted tiles). The search field in the hero must have a beautiful empty/idle look: frosted pill with a search icon, a rotating hint (cycles "Search tasks…", "Search notes…", "Search projects…" with a crossfade every 3s; strings from resources) and, on the Search screen, a lovely idle state (illustration + "Try searching for…" suggestion chips built from the user's REAL data only (recent task titles / project names / note titles, max 6) — if there is no data show an educational empty state; never fake suggestions).

## 7. App icon
Redesign the launcher icon (adaptive, vector, with monochrome layer) in the style that trends among top planner/to-do apps on Google Play: a clean rounded-square gradient background (deep indigo → violet, subtle light bloom), a bold white checkmark inside an orbit ring with one small cyan/amber satellite dot — simple, high contrast, readable at 48dp. Use WebSearch (or the browser tools) to look at the current top planner/to-do app icons on Google Play first if available and note the trend in your report; do not copy any app's mark. Also update `ic_stat_orbit` (notification icon) to a flat white version of the same mark, and the `SplashScreen`/`More`/`About` marks if they draw the old mark (they use Canvas; keep consistent: ring + check + satellite).

## 8. Ground rules for this work
No Gradle runs by agents. Never hard-code colours outside `Theme.kt` constants/tokens. All strings in resources (values/values-ur/values-es for NEW keys; the lead translates the rest later). RTL-safe, TalkBack labels, large-font safe. Do not remove public APIs that other files use (`OrbitCard`, `OrbitTopBar`, `GradientButton`, `GradientFab`, `IconTile`, `OrbitWell`, `OrbitSheet`, `ConfirmDialog`, `EmptyState`...) — extend with defaulted parameters.
