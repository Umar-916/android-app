# ORBIT Planner — design v2 brief (read together with docs/FEATURE_BRIEF.md; that file's rules still apply: NO Gradle runs, only touch the files you own, no hard-coded strings, strings in values/values-ur/values-es, RTL, accessibility, MVVM)

The design system was rebuilt following the *structure and feel* of the reference app PrankHub (floating bottom bar, floating bottom-sheet dialogs, hairline-stroked cards with glow shadows, grouped settings cards, big radii, immersive splash/premium screens) but with ORBIT's own palette: electric violet `#6C47FF` (dark: `#8A6CFF`) → purple `#A855F7` gradient, cyan `#06B6D4`, coral `#FF6B8B`, amber `#FFB020`. Light background is lavender-tinted `#F4F3FF`, dark is deep space `#0B0A1F`, cards white / `#15132E`. **Never hard-code colours** — use `MaterialTheme.colorScheme.*`, `Orbit.extras.*`, `FeatureAccent` or the designsystem constants. Never copy PrankHub code/assets; implement from this description.

## Tokens (`core/designsystem/Theme.kt`)
- `MaterialTheme.colorScheme`: primary (violet), secondary (cyan), tertiary (coral), background, surface (= card colour), surfaceVariant (track/well), onSurfaceVariant, outlineVariant, error.
- `Orbit.extras` (`OrbitExtras`): `brandGradient`, `heroGradient` (violet→magenta, for hero cards/splash/premium), `cardStroke` (hairline colour, width `cardStrokeWidth` 0.8dp), `cardGlow`, `actionGlow` (stronger glow under primary actions), `well` (inner fill for rows/chips/inputs), `textMuted`, `sectionTitle`, `isDark`, `accent(FeatureAccent)`, `accentGradient(FeatureAccent)`.
- `FeatureAccent`: HOME, TASKS (violet), PROJECTS (cyan), CALENDAR (coral), NOTES (amber), HABITS (green), GOALS (pink), ANALYTICS (blue), SETTINGS (slate), PRIVACY (teal), BACKUP (purple), PREMIUM (amber→coral). Each feature screen uses its accent for its top bar, icon tiles, FAB, chart colours and empty states, so the app is colourful but systematic.
- `Spacing` (8dp grid), `Radius` (card 20, sheet 24, button 30, chip 14, tile 14).
- Typography is in the theme (title/body/label scales). Use `MaterialTheme.typography.*`; do not set raw sp sizes.

## Components (`core/designsystem/Components.kt`) — use them, do not re-invent
`OrbitCard(modifier, onClick, contentPadding, accent: Color? = null){}` (20dp radius, hairline stroke, glow, optional coloured start edge) · `OrbitWell(modifier, onClick, selected, shape){}` (inner row/chip surface; selected = primary border) · `IconTile(icon, FeatureAccent, size=42.dp)` (gradient rounded square with white glyph + glow; the signature list icon) · `GradientButton(text, onClick, modifier, enabled, icon, brush)` (primary CTA, 52dp+, glow) · `WellButton(text, onClick)` (secondary/cancel) · `GradientFab(icon, contentDescription, onClick, label = null, brush = null)` (use for ALL FABs; pass `Orbit.extras.accentGradient(accent)` as brush for feature colour) · `OrbitTopBar(title, onBack, accent, icon, actions)` (coloured wash + optional gradient tile before the title; tab screens pass `accent`+`icon`, sub-screens pass `onBack`) · `SectionHeader`, `GroupTitle` (small grey title above a settings-style card) · `EmptyState(icon, title, message, actionLabel, onAction, accent)` · `LoadingState`, `ErrorState` · `OrbitSheet(onDismiss){}` (floating bottom-sheet dialog: inset 8dp, 24dp radius, drag handle) and `ConfirmDialog(...)` built on it — **use `OrbitSheet` for every custom dialog instead of `AlertDialog`** · `OrbitProgressBar(fraction, color)` (gradient), `ProgressRing` (gradient arc) · `TagPill`, `ColorDot`, `priorityColor/priorityLabel` · `orbitSwitchColors()`, `orbitChipColors()` (pass to `FilterChip`/`Switch`) · `Modifier.orbitGlow(shape, color, radius, offsetY)` for coloured glow shadows (replaces grey elevation; never use `Modifier.shadow`/`CardDefaults.cardElevation`).
Floating bottom navigation is hosted by the shell (`OrbitBottomBar`): tab screens must leave ~96dp of bottom padding (list `contentPadding` / last spacer) so content clears the floating bar. Material `Scaffold` for tab screens uses `contentWindowInsets = WindowInsets(0.dp)` (already the convention).
Shared helpers (`core/common/Helpers.kt`): `AppConfig` (blank constants hide features that cannot work), `tryCatch`, `ClickGuard` / `rememberClickGuard()` / `Modifier.debounceClickable`, `HideSystemBars()` (immersive screens), `Context.shareAppLink()`, `Context.openInPlayStore()`, `Context.openUrl()`, `Context.composeEmail()`. Settings now also has `runCount`, `isPremium`, `ratePromptDone` (+ `incrementRunCount()`, `setPremium()`, `setRatePromptDone()`).

## Visual rules (must hold on every screen)
1. One saturated accent family; text on gradients is white; muted copy uses `Orbit.extras.textMuted`.
2. Cards: `OrbitCard` only (same stroke, radius, glow everywhere), different *heights/layouts* per content type (hero cards 120–160dp with gradient, list cards 72–96dp, stat tiles 88–104dp, compact rows 56–64dp) — avoid a wall of identical rectangles; vary composition (icon tile left, progress right, chips below) but keep tokens identical.
3. Lists/rows inside a card are separated by a hairline divider (`HorizontalDivider(color = MaterialTheme.colorScheme.outlineVariant)`), icon tiles 42dp.
4. Primary actions use `GradientButton`/`GradientFab` with glow; secondary = `WellButton`; destructive = red gradient via `ConfirmDialog(destructive = true)`.
5. Hero areas (Home greeting, project/goal headers, premium) use `Orbit.extras.heroGradient` with large radius (28dp), white text, subtle decorative circles drawn with Canvas (orbit rings) — tasteful, not noisy.
6. Motion: subtle and purposeful — `animateFloatAsState`/`AnimatedVisibility`/`animateItem()`, staggered fade-in of hero content, spring press-scale on tiles. Respect reduced motion where trivial. No infinite animations except on splash/onboarding/premium decoration.
7. Dark theme: never pure black, never grey; backgrounds `#0B0A1F`, cards `#15132E`, strokes violet hairlines.
8. Touch targets ≥ 48dp, text ≥ 12sp, large-font safe, RTL safe (start/end), TalkBack labels preserved.

## Strings
New strings go to your own feature files as before; keep keys feature-prefixed, use `<plurals>` for counts, `%1$s` placeholders, never concatenation. Provide values / values-ur / values-es. (A later pass translates all three files into more languages — so keep every user-visible text in resources, short and clear.)
